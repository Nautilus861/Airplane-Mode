# Airplane-Mode
This repo will act as the source of truth for all documentation regarding project Airplane Mode.

# Introduction
"Project Airplane Mode" is a challenge, an opportunity to apply a chronically under-utilized understanding of the fundamentals of mechanical engineering, and most of all a monument to hubris.

While technically there is no need that drives an end product - no consumer good to market and profit from or government contract to win - this project will be treated as though there were, and therefore needs system requirements, deliverables, schedules, documentation and success criteria. That all lives here.
