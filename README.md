# Airplane-Mode
This repo will act as the source of truth for all documentation regarding project Airplane Mode.

# Introduction
"Project Airplane Mode" is a challenge, an opportunity to apply a chronically under-utilized understanding of the fundamentals of mechanical engineering, and most of all a monument to hubris.

While technically there is no need that drives an end product - no consumer good to market and profit from or government contract to win - this project will be treated as though there were, and therefore needs system requirements, deliverables, a schedule and success criteria.

# Project Overview
Brief description (elevator pitch):
Project Airplane Mode is the answer to the answer to the question "How safe can a phone case be?"
While necessarily unsafe in some ways, this case is designed not for consumer safety, but instead to convey a phone to the surface of the Earth in a controlled manner. It does this, of course, with a cold gas RCS propulsion system.
