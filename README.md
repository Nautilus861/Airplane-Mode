# Airplane-Mode
This repo will act as the source of truth for all documentation regarding project Airplane Mode.

# Introduction
Project "Airplane Mode" is a challenge, an opportunity to apply a chronically underutilized understanding of the fundamentals of mechanical engineering, and most of all a monument to hubris.

While technically there will be no end product - no consumer good to market and profit from or government contract to win - this project will be treated as such, and therefore needs system requirements, deliverables, a schedule and success criteria.
